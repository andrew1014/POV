# TestVideos — working area only

Nothing finished lives here. **Finished, upload-ready clips are in `..\Videos\`** — that is the folder to look in.

| Folder | What goes in it |
| --- | --- |
| `candidates/` | active work-in-progress renders for the clip currently being made |
| `..\Videos\` | published finals (1080x1920, audio bed, no burned text) |
| `..\Production\` | the upload package for each final |
| `..\Archive\source-raw\` | one raw HD source per shipped clip |
| `..\Archive\builds\` | recent build sources, for re-edits |
| `..\Archive\tests\` | unshipped experiments kept as evidence |

Rule: a finished clip is moved to `..\Videos\` immediately. Nothing finished is left here.
